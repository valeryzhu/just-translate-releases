从一个单词，到整篇论文

划词即译

单词优先查询离线词典；句子与段落交给翻译模型。译文可一键加入注释，后续复习直接找到。

全文与双语阅读

在 PDF 右键菜单发起全文翻译。中文与双语附件自动归档到原论文，原始文件继续保留。

多篇自动排队

一次提交多篇，逐篇处理。任务可单独取消；划词优先响应，全文任务随后继续。

三步，开始阅读

安装完整包

下载对应平台的 ZIP 并解压，运行配套安装器。在 Zotero「工具 → 插件」中，从文件安装包内的 XPI，然后重启。

准备翻译方式

打开「工具 → Just Translate」，按电脑配置选择推荐模型、确认许可并下载。准备状态与下载进度直接显示。

打开一篇 PDF

先用内置示例体验划词和注释。整篇翻译从上方工具菜单或 PDF 文件右键进入，完成后在原论文下查看附件。

已有用户：插件可通过 Zotero 自动更新；配套助手通过完整安装包升级。已有模型、论文和注释保留。下载与版本要求以最新 Release 说明为准。

默认简单，按需调整

本地翻译

HY-MT 1.8B 和 7B 可选，已有模型可直接切换。准备好模型、词典与 PDF 资源后，文本与全文翻译可在本机完成。首次准备需要网络。

已有 Agent

支持通过 ACP 连接本机已有 Agent。ChatGPT / Codex 可自动识别登录并一键连接，无需手填路径。Agent 模式依赖相应服务，文本会发给所选服务。

把参数留在高级里

处理线程、中文或双语输出、保留常见标题、人名和专有词，都按需设置。主界面只展示翻译状态、主要操作与进行中的任务。

论文阅读习惯优先

全文任务显示真实进度与排队位置；提示音可关闭。译文注释会去重，完成的译文附件留在原论文下，方便接着读。

常见问题

需要 API key 或付费订阅吗？

使用本地 HY-MT 翻译无需 API key 或云端订阅，模型在电脑上运行。选择已有 Agent 时，按该服务的账号权限、联网要求与额度使用。

为什么只安装 XPI 后，提示助手未连接？

XPI 是 Zotero 内的入口，本地助手负责模型与 PDF 处理。首次使用请安装对应平台完整 ZIP，运行安装器并安装其中的 XPI；重启 Zotero 后重新打开 Just Translate。

扫描件、公式和复杂双栏论文能翻译吗？

当前适用于有文字层的 PDF。扫描件先做 OCR。全文引擎会处理公式、表格与双栏排版，实际效果取决于原始文档；建议保留双语输出核对术语、否定句和数值关系。

可以在全文翻译时继续划词吗？

可以。本地模型优先处理划词，之后继续全文；多个全文任务逐篇执行。Agent 模式在请求边界调度，响应时间也取决于所选服务。

模型下载失败或想换一个模型，怎么办？

在设置中重新检测和下载，支持续传与完整性校验；已下载模型可直接切换。清理模型缓存也在设置里，先切换出当前模型再清理。

参考文献可以保持原文吗？

可以。在「高级」开启「保留参考文献原文」，按独立 References 等标题识别，仅影响全文翻译，划词照常可用。复杂布局可能漏保留；新开关需新版配套助手，旧助手仍可保存其他设置。

在哪里交流、反馈问题？

插件「设置 → 交流与反馈」中有 QQ 群与「小竹读研在养鱼」公众号二维码。也可以到 GitHub Issues，附操作步骤、系统和版本、错误提示；提交截图前遮住个人信息。

基于开放工具，服务科研阅读

阅读器交互基于 Translate for Zotero，全文排版使用 PDFMathTranslate-next 与 BabelDOC，本地推理使用 HY-MT 和 llama.cpp。插件与助手按 AGPL-3.0-or-later 分发，对应源码随版本提供；模型分别遵守各自许可，下载前确认。
